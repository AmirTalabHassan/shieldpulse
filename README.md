# ShieldPulse | درع النبض

أداة دفاعية ثنائية اللغة (عربي / إنجليزي) لفحص الروابط والرسائل الاحتيالية وتقييم مستوى الخطورة بوضوح.
A bilingual (Arabic / English) defensive tool to scan suspicious links and phishing messages with clear risk scoring.

## المزايا | Features
- واجهة سريعة تدعم العربية (RTL) والإنجليزية (LTR)
- تحليل الروابط والنصوص المشبوهة مع مؤشر خطورة من 0 إلى 100
- توصيات حماية فورية وسهلة الفهم

## إخلاء مسؤولية | Disclaimer
هذه الأداة مخصصة للفحص الوقائي والتوعية الأمنية فقط.
This tool is intended strictly for defensive screening and security awareness.
